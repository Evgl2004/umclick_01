# Режим очной викторины с экраном демонстрации

Документ фиксирует задание на доработку live-сценария umclick для формата, где участники физически находятся в аудитории и смотрят вопрос на общем экране.

## Цель

Сделать проведение викторины ближе к Kahoot-подобному очному сценарию:

- преподаватель управляет запуском сессии из панели ведущего;
- отдельное окно браузера работает как экран демонстрации;
- участник отвечает с телефона через крупные цветные кнопки;
- вопрос и/или тексты вариантов можно скрыть в интерфейсе участника;
- раунд автоматически проходит фазы: зачитывание вопроса, ответы, статистика, следующий вопрос;
- после завершения показывается итоговый рейтинг с подиумом.

## Настройки Викторины

В конструкторе викторины добавлены параметры:

- `Вопрос только на экране демонстрации`: участник не видит текст вопроса на телефоне.
- `Показывать варианты ответов участнику`: если выключено, участник видит только цвет, фигуру и подпись `Вариант N`.
- `Время на зачитывание вопроса`: общее время перед стартом ответов, по умолчанию 15 секунд.
- `Время показа статистики`: время показа гистограммы после раскрытия ответа, по умолчанию 10 секунд.

## Фазы Live-Сессии

Сессия хранит статус и отдельную фазу:

- `waiting`: комната создана, участники подключаются.
- `live/lobby`: игра запущена, но вопрос ещё не открыт.
- `live/reading`: на экране демонстрации крупно показан вопрос, участники ждут.
- `live/answering`: на экране демонстрации вопрос и варианты, участники отвечают.
- `live/results`: показана статистика ответов и правильный вариант.
- `finished/final`: викторина пройдена полностью.
- `aborted/final`: преподаватель завершил игру принудительно; такая сессия считается остановленной, а не штатно пройденной.

## Экран Демонстрации

Маршрут: `/display?session=<id>&api=<api-base>`.

Экран открывается из панели преподавателя кнопкой `Экран демонстрации` или автоматически при старте сессии. Его можно перевести в полноэкранный режим браузера.

Слайды:

- ожидание: название викторины, PIN, статус и число участников;
- зачитывание: крупный текст вопроса и таймер;
- ответы: вопрос сверху, цветные варианты ответов крупными плитками и основной таймер;
- статистика: гистограмма по вариантам, правильный ответ отмечен явно;
- финал: подиум первых трёх мест и общий рейтинг.

## Экран Участника

Участник видит:

- форму быстрого входа;
- сообщение `Смотрите на экран демонстрации` на фазе зачитывания;
- во время ответа: крупные цветные кнопки с фигурами;
- после раскрытия: зелёная рамка и галочка на правильном варианте;
- в финале: свой результат и общий подиум.

## Результаты И История

Для каждой сессии сохраняются:

- участники;
- ответы на каждый вопрос;
- начисленные очки;
- время ответа в миллисекундах;
- статус завершения.

Рейтинг сортируется по очкам, затем по числу правильных ответов, затем по суммарному времени ответа. Это позволяет корректно разруливать равные баллы.

В панели преподавателя добавлен блок истории проведённых викторин:

- список последних сессий;
- статус и число участников;
- быстрый экспорт CSV;
- просмотр итогового рейтинга по выбранной сессии.

## Повторные Запуски

Одна и та же викторина может запускаться много раз. Для каждой новой live-сессии варианты ответов перемешиваются детерминированно на уровне пары `сессия + вопрос`, поэтому правильный ответ не остаётся постоянно на одной позиции.

## Критерии Приёмки

- преподаватель может создать викторину с новыми настройками;
- после старта открывается отдельный экран демонстрации;
- участник не видит вопрос и/или тексты ответов, если это отключено в настройках;
- фазы автоматически переходят по таймерам;
- после завершения показывается итоговый рейтинг;
- принудительное завершение переводит сессию в статус `aborted`;
- история сессий доступна преподавателю;
- backend и frontend проверки проходят, Flutter Web сборка создаётся успешно.
